# Fotora 界面与功能优化记录

本文件记录本轮优化前完成的功能盘点、采用的技能和分步计划。优化过程以现有
Electron + 原生前端结构为基础，不更换技术栈，也不改变照片原文件。

## 二、关键关联流程

1. **图库 → 相簿 → 照片墙**：相簿统计与封面共用索引；照片墙必须保留当前
   图库来源、选中相簿集合和独立裁剪。
2. **网格 → 查看器 → 编辑器**：打开时从缩略图飞行进入，编辑后原位刷新并
   保持当前滚动位置；关闭时返回对应格子而不是固定中心。
3. **查看器 → 信息卡 → 时间/位置编辑**：时间变化可能改变时间分组，位置变化
   可能改变位置筛选，因此需要刷新控件内容并在必要时平滑重排。
4. **多选 → 元数据/移动/删除/编号**：操作成功后立即补位，接口失败时恢复快照；
   多选状态不能重建整片网格或跳回顶部。
5. **图库/相簿 → 地图 → 胶片栏 → 查看器**：地图胶片、聚合标记和查看器使用
   同一项目身份；退出时恢复来源滚动位置和隐藏逻辑。
6. **设置 → 运行时预览 → 保存/取消**：分段选项先即时预览，离开设置时统一
   应用或还原；主题、语言和 iframe 页面通过同一信号同步。

## 三、技能匹配

| 优化范围                           | 采用的技能              | 使用方式                                     |
| ---------------------------------- | ----------------------- | -------------------------------------------- |
| 全局视觉层级、可读性、信息密度     | `emil-design-eng`       | 统一表面、留白、文字对比和内容优先级         |
| 图库、相簿、长标题、空字段、大计数 | `break-ui`              | 用长名称、缺失元数据、大数量和 900×600 验证  |
| 选择栏、菜单、查看器快捷反馈       | `review-animations`     | 删除高频/键盘操作的装饰动效，检查时长与缓动  |
| 大图、地图、胶片与虚拟网格         | `animation-performance` | 优先使用合成属性，避免不必要的布局和滤镜重绘 |
| 查看器平移、胶片拖动、相册拖排     | `gestures`              | 检查 1:1 跟踪、边界阻尼和释放后的收敛        |
| 照片墙多元素入场与跨区域切换       | `choreograph`（后续）   | 协调主表面、照片、控制栏和加载层的顺序       |

## 四、分步优化顺序

### 第一轮：全局可用性与信息清晰度（已完成）

- [x] 修正视口高度不足时，弹层被顶栏覆盖的问题。
- [x] 信息卡只在存在真实参数时显示参数行，避免连续空占位。
- [x] 提高查看器计数在复杂照片背景上的可读性。
- [x] 让键盘触发的收藏与评级直接更新，不播放鼠标操作才需要的回弹。
- [x] 对大计数使用本地化数字分组，避免长数字难以扫读。
- [x] 为被省略的相簿名、标题和文件名补充完整名称提示。

### 第二轮：图库与相簿主流程（已完成）

- [x] 复核窄窗口下的标题、工具栏、侧栏和相簿卡片长名称。
- [x] 被截断的相簿名、工具栏标题和文件名提供完整名称提示。
- [x] 优化选择计数的大数字分组，同时保留原计数滚入动画。
- [x] 将易混淆的“类型筛选 / 类型过滤”改为“媒体类型 / 文件格式”。
- [x] 复核相簿切换、排序、删除与多选批处理后的连续补位。

### 第三轮：查看器与编辑器联动（已完成）

- [x] 优化信息卡缺失参数、查看器计数和键盘操作反馈。
- [x] 避免计数胶囊与查看器胶片栏互相遮挡。
- [x] 查看器放大后平移限制在画面边界内，越界拖动使用阻尼并自动收敛。
- [x] 复核大图翻页与编辑入口在 900×600 和默认窗口下的层级。
- [x] 检查编辑器保存后焦点、返回位置和缩略图刷新。
- [x] 移除编辑器工作区未使用的布局属性过渡。

### 第四轮：照片墙、地图与幻灯片（已完成）

- [x] 窄窗口照片墙风格入口固定为 2×2，避免 3 + 1 的孤立换行。
- [x] 风格切换改成内容容器的单次 220ms 入场，可中途接管，不再逐卡排队。
- [x] 统一四种照片墙的局部选择状态与相簿数量格式。
- [x] 提高卫星地图按钮图标与玻璃底的对比度，并跟随明暗主题文字色。
- [x] 复核地图控件显隐、胶片拖动和位置分配完成后的返回路径。
- [x] 幻灯片计数使用分组数字，长标题最多两行并提供完整名称提示。
- [x] 检查幻灯片字幕、控制条与结束卡在不同窗口高度下的避让。

### 第五轮：编辑器功能补齐（已完成）

- [x] 在“裁剪 / 几何”之间切换，两种工具各有独立工具栏。
- [x] 增加逆时针、顺时针 90° 旋转及水平镜像。
- [x] 增加 ±45° 拉直滑杆、角度读数和几何重置。
- [x] 客户端预览按后端几何滤镜的同一顺序反向采样。
- [x] 旋转、镜像、拉直和透视字段不再在编辑配方中被丢弃。
- [x] 支持撤销、重做、取消、保存以及前后端真实输出验证。

### 第六轮：悬停提示清理（已完成）

- [x] 删除侧栏、相簿卡片、查看器、设置、幻灯片和地图按钮的
      `title` 悬停提示。
- [x] 删除自定义 `data-tooltip` 入口，鼠标在任意控件上停留都不再弹出文字框。
- [x] 图标按钮继续使用 `aria-label`，说明内容改用 `aria-description`，
      删除鼠标提示不会连带丢失键盘和读屏可访问性。
- [x] 新增源码回归测试，防止后续重新引入原生或自定义悬停提示。

### 第七轮：角落控件材质统一（已完成）

- [x] 顶栏左侧时间分组、右侧选择 / 菜单 / 三点按钮在鼠标靠近时
      使用主菜单同一套玻璃填充和背景模糊变量。
- [x] 左上角热区将相簿栏开关与时间分组合并计算，开关的透明描边也使用
      同一层菜单玻璃材质。
- [x] 靠近材质只用于透明标题栏下的图库与相簿；实色和模糊标题栏完全不
      响应鼠标距离，不残留阴影或底材变化。
- [x] 显示地图不参与靠近材质变化，地图内按钮保持原有显隐与悬停逻辑。
- [x] 地图收起相簿栏后，父页面展开 / 收起按钮固定复用地图三颗圆钮的
      控制底材、模糊和描边，并同步矢量图与卫星图的明暗材质。
- [x] 顶栏左右两侧独立感知鼠标，靠近一侧不会带动另一侧。
- [x] 选择模式底栏左右操作按钮采用相同材质，左右下角同样独立响应。
- [x] 菜单或目标相簿浮层打开时，触发角保持玻璃材质，鼠标移入浮层不闪回。
- [x] 热区改为从按钮组布局位置向上下左右统一扩展 42px，不再向按钮
      下方单独拉出一大片区域。
- [x] 使用 `offsetLeft / offsetTop / offsetWidth / offsetHeight` 计算
      布局锚点，不受按钮悬停缩放和入场动画影响。
- [x] 热区外只增加 4px 进入边界和 28px 离开边界；离开后再等待
      110ms，期间重新靠近会取消恢复。
- [x] 仅在状态变化时更新 DOM，避免鼠标停在边界时反复切换。
- [x] 材质变化不修改宽高、内边距或定位，不引发布局跳动。

### 第八轮：可见优先加载与地图渐进更新（已完成）

- [x] 新图库的结构扫描完成后先进入“可浏览”，拍摄信息和 GPS 在后台
      按批次继续，不再等全库元数据完成后才显示照片。
- [x] 地图先显示已读取完成的 GPS；后续批次通过 iframe 差量消息补充，
      不重载地图、不重新飞行、不清空当前选择。
- [x] 地图标记统一先显示 48px L0，再升级到 128px / 200px；Canvas 与 DOM
      共用缩略图缓存，快速移动地图时只保留当前视野附近的图片任务。
- [x] 时间按钮的远距离跳转先准备终点首屏，再直接落位；中间位置不再进入
      缩略图和高清预生成队列。
- [x] 空闲时继续持久化全库 L0，但高清 L1 只预热当前视野附近，避免软件
      停在图库时长期处理整库高清缩略图。
- [x] L0 新增图集页：每页最多 64 张微型预览，一页一次请求；空闲时逐页
      持久化，单张 L0 只在图集尚未到达时作为回退。
- [x] Ctrl+滚轮与触控板捏合改为连续 GPU 缩放预览：手势期间不重排网格，
      不重建窗口，也不启动逐档 FLIP；手势停下后才提交到最近档位一次。
- [x] 缩放锚点只在手势开始时捕获一次，缩小和放大都围绕鼠标下的同一照片
      相对位置；停止预览、虚拟布局与 CSS 档位统一使用同一张倍率表，消除
      预览结束后落错档或二次跳动。
- [x] 图集页键复用当前已渲染内容的签名，不再为每个新格子重扫全库；实测
      7,361 张图库从标准档提交到相邻缩小档的同步耗时为 75ms，原先约 2.7 秒。
- [x] 后台预热的 L0 回收时统一去掉 `lane=background` 再入池，避免离屏图
      只能复用一次；同一照片连续重建格子可直接领回同一张已解码图片。
- [x] 图集只在整页所有格子都生成成功后才落盘，并保留重复项目的原始槽位；
      单张失败时由逐张 L0 回退，不再让半成品图集遮住透明空洞。
- [x] 后台图集改为低网络优先级；失败页会从缓存删除，下一次视野进入或格子
      重建时重新请求，不再一次超时后永久退化成单张 L0。
- [x] 每个图集页写入同名依赖清单；编辑、替换或删除照片时只让包含该照片的
      图集页失效，其他页继续命中，不再因为一张变化清空整座图集缓存。
- [x] 图集 URL 携带独立格式版本，服务端生成规则升级后浏览器不会继续使用
      旧响应；生成任务落盘前再次核对项目版本，失效后不会写回过期页面。
- [x] 按项目 ID 清理 RAW 的 `raw-v3` 嵌入预览、临时预览和嵌入拼图墙缩略图；
      封面刷新只重做封面单图，不连带重建仍然有效的图集页。
- [x] 鼠标 Ctrl+滚轮改为严格一格一档，同一连续滚轮手势里的后续事件在
      140ms 闲置窗口内合并；触控板捏合仍保留连续跟手和一次提交。
- [x] 窗口化网格不再对真实可见格使用 `content-visibility:auto`。大幅换档后
      Chromium 曾沿用旧裁剪范围，DOM 和图片已经就绪，下半屏却要滚动 1px
      才重绘；现在 7,361 张图库缩到最小档时，1,302 个可见格一次完整绘制。
- [x] 元数据后台完成导致排序变化时保留当前照片作为视口锚点，不把正在看的
      照片突然换走。

### 第九轮：照片浏览全链路缓存（已完成）

- [x] 图集页常驻上限从 24 页提升到 128 页，覆盖常见 8,000 张图库；
      四页并行预热，已加载页不会在每次 render 时重复排队。
- [x] 图集页尚未进内存时，新格子从创建当帧就请求单张 48px L0，
      快速滚动和任意跳转首帧不再停在整屏空白骨架。
- [x] L0 图集完成后，以 48 张一批、320ms 间隔在后台补齐当前图库全部
      400px 标准网格图；任何可见区请求仍可把后台任务提升到前台。
- [x] 全库标准图完成状态按图库身份和 revision 持久化，普通重启不再对
      已完成图库重复扫描；新增、替换或编辑照片后会自动重新补齐。
- [x] 网格不同尺寸共用一个解码节点预算，布局与普通缩放切换时继续保留
      已解码节点，不再整池作废。
- [x] 普通缩略图从“五档各换一份 URL”改为统一 192px 网格底图；四种布局与
      1～5 档缩放共用同一个底层地址，标准档及以上只叠加可见区的 400px 细节层。
- [x] 小档格子从约 30px / 57px / 99px 提高到约 61px / 87px / 122px，
      减少一屏 DOM、L0 解码和单独缩略图请求数量。
- [x] 标准档滚动后新补出的虚拟格子重新接入 400px 细节层观察器；离开窗口时
      同步解除观察，避免滚到新位置后只剩轻量底图而变糊。
- [x] 换档快照使用固定裁切壳承载内部缩放，旧画面、真实新网格和同一索引的
      重复节点不会同时露出两套上下错开的布局。
- [x] 虚拟窗口改读动画前记录的稳定网格内容坐标，交叉淡化的 `scale()` 不再
      污染 `getBoundingClientRect()`，换档结束后不会跳到几千张之外或露出空洞。
- [x] 连续滚轮按事件时间戳去重，动画期间的新目标和反向手势可以排队；
      连续手势沿用手势开始时指针下的同一张照片，避免多轮往返逐次漂移。
- [x] 整库虚拟布局按视图、revision、尺寸和布局模式缓存，在有限 LRU 中
